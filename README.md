#  AdaptEval: Domain Adaptation Evaluation Suite

[![Paper](https://img.shields.io/badge/arXiv-2407.11591-B31B1B.svg)](https://arxiv.org/abs/2407.11591)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Python 3.8+](https://img.shields.io/badge/python-3.8+-blue.svg)](#)

**AdaptEval** is a specialized framework designed to evaluate the domain adaptation capabilities of Large Language Models (LLMs) in text summarization. Developed as part of the research presented at **ACL 2024 (CustomNLP4U)**, it provides tools to measure how well models transition across diverse domains using both standard and distribution-based metrics.

---

##  Key Features
* **Multi-Metric Suite:** Integrated support for ROUGE, BERTScore, and Domain Vocabulary Overlap.
* **Token Distribution Shift (TDS):** Scripts to quantify the shift in model output when moving between zero-shot, few-shot, or base vs. fine-tuned settings.
* **LLM-as-a-Judge:** Automated evaluation scripts using GPT-4.
* **Workflow Efficiency:** Manage experiments via centralized JSON configurations.

## 🛠 Setup & Installation

## Data Preparation

To ensure the scripts can automatically parse model names and datasets, your input CSV files **must** follow this naming convention:

`{prefix}_MODEL_{model_name}_TASK_{dataset}_{task}.csv`

### Required CSV Columns:
| Column | Description |
| :--- | :--- |
| `reference` | The ground truth (gold standard) summary. |
| `prediction` | The summary generated by the LLM. |
| `prompt_0` | The full prompt text (required for Token Distribution Shift scripts). |

## Usage

The framework is configuration-driven. Before running scripts, ensure your paths are correctly set in `configs/config.json`.

### 1. Reference-based Evaluation
Run this to calculate ROUGE, BERTScore, and Domain Vocabulary Overlap:
```bash
python compile_results.py --config configs/your_config.json
```

### 2. Token Distribution Shift (Zero-Shot vs. Few-Shot)
Analyze how adding examples to the prompt shifts the model's output vocabulary:
```bash
python token_dist_shift_few_shot_zero_shot.py --config configs/your_config.json
```

### 3. Model Distribution Comparison
Compare the output distribution between two different models (e.g., a base model vs. a fine-tuned version):
```bash
python token_dist_shift_model2_model1.py --config configs/your_config.json
```

## 📊 Evaluation Metrics

* **ROUGE (1, 2, L):** Measures lexical n-gram overlap.
* **BERTScore:** Captures semantic similarity using contextual embeddings.
* **Domain Vocabulary Overlap:** Specifically tracks the inclusion of domain-specific technical terms.
* **TDS (Token Distribution Shift):** A statistical approach to quantify how much the model's "internal" vocabulary changes across domains or prompts.
* **GPT-4 Eval:** Qualitative scoring based on coherence, relevance, and factual consistency.
